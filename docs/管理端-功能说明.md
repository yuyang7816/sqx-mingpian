# 管理端功能说明

管理端是给平台工作人员用的网站，在电脑浏览器里打开。名片用户不使用这个网站。它用来看经营和用户、审核名片与认证、处理订单和提现，以及填写微信、支付宝、短信、图片存储、地图这些外面服务的账号。

程序里的名称是「省钱兄名片分享系统」。工作人员登录后，左侧是菜单。能看到哪些菜单，由管理员给这个账号分配的权限决定。没有权限的菜单不会出现。

下面的菜单名称来自导入的数据库和路由配置。如果你后来在「菜单管理」里改过名字，以你屏幕上看到的为准。

## 登录

登录页要填账号、密码，还要看一张图片验证码。看不清就点图片换一张。验证码由服务端生成。服务端没启动时，图片是裂的，登录也会失败。

导入 `mpfx.sql` 之后，演示账号是 `admin`，密码是 `123456`。开源使用时建议只使用 `admin`，或在「管理员列表」里自己新建。

## 登录之后第一眼：数据中心

登录后的首页用来看平台概况，数字来自自己的数据库，不连接外面的报表公司。

具体有哪些数字，以页面上显示的为准。它用来知道有没有新用户、订单和待处理事项，不是在这里替用户付款。

## 用户和名片

### 用户列表 / 用户详情

看注册用户。可以点进用户详情，看这个人的账号、名片和认证情况。有权限时可以删除用户。删除是后台操作，不是用户自己在手机上点注销的那一步。

### 名片管理

看用户创建的个人名片、企业名片。可审核通过或拒绝。用户端展示与否，和审核状态、展示状态有关。

### 名片样式 / 模板管理

维护用户端可选的名片样式、企业模板等。用户端「更换样式」「编辑模板」读的就是这些配置。

### 企业管理 / 入驻申请

企业相关审核、封禁、上架、推荐。用户端「企业」页和企业成员管理与这里配套。

### 认证审核

用户在手机上提交认证之后，申请出现在这里。

- 通过：用户端认证状态变成已通过。
- 拒绝：用户端显示已拒绝，对方需要重新提交。

### 注销信息

用户在设置里申请注销账号后，记录出现在这里。这是人工处理注销，不是用户一点、账号立刻从库里消失。

### 名片申请 / 名片排行榜

处理名片相关申请，查看榜单数据。

## 内容和装修

### 首页装修 / Banner

决定用户端相关展示图、运营位。改完保存后，用户下次打开才会变。

### 帮助中心

帮助文章。用户端「帮助中心」点进去看的就是这些文章。

### 动态列表

企业或用户发布的动态。可以查看、处理不合适的内容。

### 行业分类 / 筛选配置

人脉搜索、行业相关筛选项。改的是筛选项本身，不是某一张名片的内容。

## 会员和钱

### 会员配置 / 会员特权

会员卖多少钱、开通之后用户能多做什么。用户端「会员中心」读的是这些配置。

### 点数充值配置 / 充值记录

钱包或点数相关档位与记录。

### 订单中心

会员、充值等已经产生的订单。用来核对谁买了、付了没有、是否还在待付款。真正扣款发生在用户付款的那一刻，这个页面是事后查看。

### 财务中心

看资金记录。有权限时可以处理退款、转账相关操作。

用户提现也在资金相关页面里处理。点通过表示平台同意打款。系统不会自动调用微信「企业付款」或支付宝转账把钱转走，打款仍要按用户留下的提现账号人工处理。

### 发票管理

有开通时，处理用户发票相关申请。

## 消息

### 消息中心

给用户发站内消息。用户在消息相关入口里看。这不是短信。

### 聊天记录

如菜单开放，可查看相关会话，用来处理投诉和审核。工作人员不是在这里代替某个用户继续聊天。

## 系统配置：外面那些服务的账号都在这里

这是和第三方关系最大的一页。短信、微信支付、支付宝、图片存到哪一家、地图 Key、客服微信和电话，都在「系统配置」里改。

改完要保存。用户端下次请求才会用新的密钥。只在用户端改文字，不会变成已经开通了支付。

开源 SQL 里下列项已清空，需要自己填：

- 客服微信号、客服电话、客服二维码、企业微信客服
- 腾讯地图 Key、天地图 Key
- 短信、微信支付、支付宝、对象存储密钥

图片存储可选本地或云存储（阿里云 OSS、七牛、腾讯云）。开源默认偏向本地上传；要用云存储时再填对应密钥。

短信可以切换腾讯云、阿里云或短信宝。三家都要在对方网站申请签名，只把程序跑起来不会自动拥有短信额度。

客服也在这里改：

- **客服类型**：电话、企业微信，或客服二维码。
- **客服电话、客服微信号、客服二维码**：用户端「客服中心」会按类型使用。

## 系统管理

「系统管理」是给工作人员账号用的，名片用户看不到：

- **管理员列表**：后台登录账号。可以新增工作人员。
- **角色管理**：一组权限的名字，例如只让某个人看用户、不能改财务。
- **菜单管理**：左侧有哪些菜单。改错了可能导致某个页面从菜单里消失。
- **字典**：下拉选项一类基础数据。
- **升级配置**：手机 App 要不要提示升级。只做网页预览时可以先不管。
- **微信配置**：小程序 / 公众号相关配置入口（具体以页面为准）。

## 这些页面是框架留下的

路由里还能看到陪玩、美食、礼品一类页面。那是这套后台模板带过来的，左侧菜单里没有的就不用找。名片分享日常以用户、名片、企业、会员、订单、财务、系统配置为主。

## 和用户端怎么配合

管理端不自己保存订单终态。它把操作发给服务端，服务端再写入数据库。所以：

- 服务端没开时，管理端登录不了。
- 改完会员价、客服电话、样式后，要保存；用户端下次打开才变。
- 审核通过名片或认证后，用户端状态才会更新。
