# 管理端运行教程

按顺序做。这是电脑浏览器里的后台，不是手机应用。代码在 `mingpian-admin` 文件夹。程序名称是「省钱兄名片分享系统」。

先按 [服务端运行教程](服务端-运行教程.md) 把数据库导入并启动服务端。服务端窗口里要已经出现「名片分享启动成功」，并且那个窗口不能关。服务端没启动时，这个网站打得开，但验证码图片是裂的，登录会失败。

## 开始之前要准备什么

安装 Node.js 18 或 20：https://nodejs.org/

这个后台用的是较老的 Webpack 4。Node 17 及以上有时会遇到 OpenSSL 相关报错。推荐用 **Node 18**。如果 `npm run dev` 报 `error:0308010C:digital envelope routines::unsupported`，在启动前执行：

```powershell
$env:NODE_OPTIONS="--openssl-legacy-provider"
```

安装时勾选添加到 PATH。安装完成后，重新打开 PowerShell，输入：

```powershell
node -v
npm -v
```

两行都有版本号才算成功，例如 `v18` 或 `v20`，以及 `8.x` 以上。只看到「不是内部或外部命令」时，关掉窗口再开一次；还是没有，就重新安装 Node.js 并勾选 PATH。

浏览器使用 Chrome 或 Edge。

## 第 1 步：确认连的是自己电脑上的服务端

当前工程里，接口地址在 `src/utils/httpRequest.js` 里写死成了线上域名，开发时代理那段代码被注释掉了。本机调试时，要用记事本或编辑器打开：

`mingpian-admin/src/utils/httpRequest.js`

找到 `adornUrl`、`adornUrlUp` 里类似下面的地址：

```javascript
return 'https://mpfxadmin.xianmaxiong.com/sqx_fast/' + actionName
```

改成：

```javascript
return 'http://127.0.0.1:7777/sqx_fast/' + actionName
```

两处都要改。`adornWss` 现在写死了 `wss://mpfxadmin.xianmaxiong.com/wss/`。登录、看用户、审核名片不依赖它。要在后台里测实时相关能力时，再按服务端实际地址改。

可选：`config/index.js` 里仍有 `proxyTable`，目标可改成 `http://127.0.0.1:7777/sqx_fast/`。但当前 `httpRequest.js` 没有走 `/proxyApi`，所以**只改代理不够**，必须改 `httpRequest.js`。

`static/config/index-prod.js` 是打包后的地址。只在自己电脑里 `npm run dev` 时，可以先不改。以后要打包给别人用，再把里面的 `baseUrl` 改成你的服务端地址。

改完之后，如果网站已经在运行，要先停掉再启动，修改才会生效。

## 第 2 步：安装依赖

在 `mingpian-admin` 文件夹里打开 PowerShell（在文件夹空白处按住 Shift，右键，选「在此处打开 PowerShell 窗口」或「在终端中打开」），执行：

```powershell
npm install
```

第一次可能要几分钟到十几分钟。结束时没有红色 `npm ERR!`，并且这个文件夹里出现 `node_modules`，就成功了。

## 第 3 步：启动网站

还是在 `mingpian-admin` 文件夹里执行：

```powershell
npm run dev
```

窗口里会出现本地地址。默认端口是 **8001**，配置里 `autoOpenBrowser` 是打开的，浏览器一般会自己弹出。没有自动打开时，手动打开：

http://localhost:8001

登录页上应能看到一张验证码图片。看不清就点图片换一张。验证码来自本机服务端。图片是裂的，说明第 1 步的地址不对，或服务端没有启动。

这个 PowerShell 窗口也要一直开着。

## 怎样算成功

使用导入库里的演示账号登录。用户名是 `admin`，密码是 `123456`。登录成功后进入首页数据中心，左侧能看到菜单，例如用户列表、名片管理、企业管理、订单中心、财务中心、系统配置。某个菜单没有出现，是这个账号的角色里没勾选它，到「角色管理」里勾上再重新登录。

名片列表是空的，不代表后台没连上。用户要在用户端注册并创建名片之后，这里才会有数据。

## 常见问题

**`npm` 不是内部或外部命令**  
Node.js 没装好，或安装后没有重新打开 PowerShell。

**`error:0308010C:digital envelope routines::unsupported`**  
Node 版本偏新与 Webpack 4 冲突。设置 `$env:NODE_OPTIONS="--openssl-legacy-provider"` 后再 `npm run dev`，或改用 Node 18。

**浏览器打不开 localhost:8001**  
看 `npm run dev` 的窗口是否还在。窗口里如果写的是别的端口，用窗口里打印的那个地址。配置里的 `host` 是 `0.0.0.0`，本机用 `localhost` 或 `127.0.0.1` 都能开。

**验证码不显示，或登录提示网络错误**  
服务端没启动，或 `httpRequest.js` 仍指向 `mpfxadmin.xianmaxiong.com`。按键盘 `F12`，点「网络」或 Network，再点一次登录。请求应发到 `127.0.0.1:7777`。改完后在运行窗口按 `Ctrl+C` 停掉，再执行一次 `npm run dev`。

**`Port 8001 is in use`**  
8001 已被占用。关掉之前的管理端窗口再启动。

**登录提示验证码不正确**  
图片上的字要和输入完全一致，区分大小写。点图片换一张再试。服务端窗口如果已经关掉，验证码对了也登不进去。
