# 服务端功能说明

服务端没有给名片用户点的页面。它是一直开着的程序：用户端和管理端把「登录、名片、企业、付款」这些请求发给它，它检查是否允许、把结果存进数据库，必要时再去问微信、支付宝、短信这些外面的服务。

可以把它理解成总台。两个前台（用户端、管理端）说的话，都由总台记账，并在需要时给外面的公司打电话。

数据库配置在 `service/src/main/resources/application-prod.yml`。库名是 `mpfx`，导入文件是 `service/db/mpfx.sql`。名片、企业、订单、访客、钱包都记在这里。

启动类是 `com.sqx.SqxApplication`。端口是 **7777**，所有接口都在 `/sqx_fast` 下面。接口列表在：

http://127.0.0.1:7777/sqx_fast/swagger-ui.html

Redis 写在配置里，地址是本机 `6379`。当前 `spring.redis.open` 和 `sqx.redis.open` 都是关的，所以它不是必须先启动的。如果以后把开关打开，就要先启动 Redis，密码和配置文件一致。

下面先说它为两个前台做哪些事，再说它会主动连接哪些外面的服务。

## 它为名片用户做的事

这些都是用户在手机里点一下之后，由服务端完成的：

- **注册和登录**：检查手机号和短信验证码，或检查密码。通过后发给用户一张登录凭证。之后每个请求都要带这张凭证，否则视为没登录。
- **绑定手机号、修改手机号、找回密码、修改密码**：再次核对短信或原密码，然后改资料。
- **个人名片 / 企业名片**：保存名片内容、样式、审核状态；返回名片详情；记下谁访问了谁，供「最近访客」「最近查看」使用。
- **名片夹与互换**：记下收藏、互换次数与相关记录。
- **企业主页**：企业名片、成员、企业动态、入驻或加入申请。
- **人脉搜索、名片榜单**：按条件查名片与人气相关数据。
- **拍摄识卡相关上传**：接收名片图片，按系统配置存到本机或对象存储。
- **认证**：保存用户上传的认证材料，状态先是待审核。管理端通过或拒绝之后，再把新状态发给用户端。
- **会员**：读取会员价格和特权，生成开通订单。支付结果以微信或支付宝的通知为准。
- **钱包**：余额、充值入账、提现申请、资金明细。提现只生成一条待审核记录，不会在这一步把钱转到对方支付宝。
- **邀请与团队分销**：记录邀请关系，供「我的团队」「我的收益」显示。
- **AI 核查**：按配置调用外部能力核查企业信息（密钥在系统配置）。
- **消息、帮助、反馈、协议、关于我们**：把后台维护的内容发给用户端。
- **注销**：记下注销申请，交给管理端「注销信息」处理。
- **客服展示**：把系统配置里的客服类型、电话、微信号、二维码、企业微信链接发给用户端。

## 它为管理端做的事

- 工作人员登录，并按角色限制能看的菜单。登录验证码也由它生成。
- 提供数据中心要用的统计数字。
- 保存用户、名片审核、企业管理、模板与样式、动态、公告、帮助、首页装修、会员价格和特权。
- 订单和财务记录。退款一类操作会改订单或资金状态。原路退回微信或支付宝时，仍然要支付密钥有效。
- 查看聊天或消息相关记录（若菜单开放）。
- 保存系统配置。用户端下次请求时读到新的短信、支付、图片存储、地图与客服配置。
- 管理员、角色、菜单、字典。

## 对接了哪些外面的服务

下面每一项都是服务端真的会向外发送请求的。密钥没填时，它不会假装成功，用户端会看到失败提示。

### 短信

注册、验证码登录、找回密码、修改手机号，都由服务端发短信。

可以切换三家，后台「短信服务商」可配腾讯云、阿里云或短信宝：

- 腾讯云短信：https://cloud.tencent.com/product/sms
- 阿里云短信：https://www.aliyun.com/product/sms
- 短信宝：https://www.smsbao.com/

短信签名和模板要在对方网站申请。只把程序跑起来，不会自动拥有短信额度。

### 微信支付

用户选择微信支付时，服务端用商户号和密钥向微信支付下单，并把拉起支付需要的信息交回手机。支付完成后，微信访问服务端的通知地址，服务端核对之后，再把订单改成已支付。

用在：开通会员、充值，以及其他页面上的微信支付。

还需要微信公众平台上的小程序或公众号 AppId：https://mp.weixin.qq.com/ 。商户平台在 https://pay.weixin.qq.com/ 。

### 支付宝

和微信同一类流程：下单、拉起支付宝、等待支付宝通知。需要支付宝开放平台的应用编号和密钥：https://open.alipay.com/ 。

### 图片存储

用户和管理端上传的图片（头像、名片图、企业资质、认证材料）由服务端接收，然后按「系统配置」里选中的方式保存：

- 本地硬盘（开源默认常配成本地）
- 阿里云 OSS：https://www.aliyun.com/product/oss
- 七牛云：https://www.qiniu.com/
- 腾讯云对象存储：https://cloud.tencent.com/product/cos

选云存储但密钥没填时，上传会失败。

### 地图

系统配置里可选腾讯地图或天地图，并填写对应 Key。管理端或用户端需要选点、定位时会用到。百度相关配置项也在系统配置里，未填则不用。

- 腾讯位置服务：https://lbs.qq.com/
- 天地图：https://www.tianditu.gov.cn/

### 企业微信客服

系统配置里的客服类型选成企业微信时，用户在微信小程序里点「客服中心」，会按配置的企业 ID 和客服链接打开企业微信客服。官网：https://work.weixin.qq.com/ 。类型选成电话或客服二维码时，不会走这一步。

### AI 核查

「AI 核查企业」依赖系统配置里的相关 API Key（如 qwen-apikey）。没填时核查接口会失败。

## 这些不是外面的公司

- **余额支付**：只改数据库里的钱包数字。
- **提现**：只保存收款账号和金额，等管理端审核。没有向微信或支付宝自动打款。
- **名片收藏、访客、互换、邀请关系**：都在自己的数据库里。
- **客服微信号和二维码**：只把后台填的内容展示给用户，不会自动加好友。
- **操作日志、权限、角色**：只约束管理端工作人员。

## 两个前台怎样和它配合

用户端和管理端都不直接保存订单和名片审核结果。它们把请求发给服务端，服务端再决定要不要去问微信、短信或图床。

所以：

- 服务端没启动时，两个网站都能打开界面，但登录、列表、付款都会失败。
- 外面的密钥只配在服务端能读到的「系统配置」里。只在用户端页面上改文字，不会变成已经开通了微信支付。
- 管理端改完会员价格、客服电话、公告并保存后，用户端下次打开才会看到新内容。
