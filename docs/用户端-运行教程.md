# 用户端运行教程

按顺序做。这是给手机和网页用的应用，窗口标题是「名片分享」。用 HBuilderX 打开 `uniapp` 文件夹来运行。

先按 [服务端运行教程](服务端-运行教程.md) 导入 `service/db/mpfx.sql` 并启动服务端。首页上的名片数据来自这个库。服务端没启动时，页面也许能打开，但数据是空的，登录会失败。

## 开始之前要准备什么

安装 HBuilderX：https://www.dcloud.io/hbuilderx.html

下载「正式版」。解压或安装后，打开软件，窗口标题是 HBuilderX，就说明安装成功。

安装 Node.js（建议 18）：https://nodejs.org/

`uni_modules/uview-plus` 是界面组件，已经在项目里。日历、日期选择还会从项目根目录的 `node_modules` 引用 npm 包 `dayjs`。仓库不带 `node_modules`，没装依赖时，运行到浏览器会报 `Failed to resolve import "dayjs/esm/index"`。

在 `mingpian-uniapp` 目录（文档里也写作 `uniapp`）打开终端，执行：

```powershell
npm install
```

结束时没有红色 `npm ERR!`，并且出现 `node_modules\dayjs`，就成功了。然后再用 HBuilderX 运行。

只在电脑浏览器里看时，不需要微信开发者工具。要在微信里看，再安装微信开发者工具：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

## 第 1 步：确认连的是自己电脑上的服务端

用 HBuilderX 或记事本打开 `uniapp/common/config.js`。文件最上面现在指向线上域名。改成：

```javascript
const ROOTPATH1 = "http://127.0.0.1:7777/sqx_fast";
const ROOTPATH = "http://127.0.0.1:7777/sqx_fast";
```

两行都要改。保存文件。

下面几处上传地址是写死在页面里的，不读 `config.js`。只浏览、登录时可以先不改。要点「上传头像、名片图」并传到自己的服务端时，把里面的 `https://mpfx.xianmaxiong.com/sqx_fast/alioss/upload` 改成 `http://127.0.0.1:7777/sqx_fast/alioss/upload`：

| 要测的功能 | 文件 |
|---|---|
| 首页名片相关上传 | `pages/index/index.vue` |
| 我的资料 / 个人信息 | `pages/my/userInfo.vue`、`pages/my/info.vue` |
| 企业页相关上传 | `pages/Enterprise/index.vue` |

同一页里如果有一行已经写成 `config.APIHOST + '/alioss/upload'`，那一行会跟着第 1 步的配置走，不用再改。被注释掉的行也不用改。

部分分享图、静态图标仍可能写着原来的线上图片地址。本机没有那张图时，个别图可能裂开。名片接口数据本身不依赖那些外链图。

## 第 2 步：用 HBuilderX 打开项目

1. 打开 HBuilderX。
2. 菜单选「文件」→「打开目录」。
3. 选中 `uniapp` 这个文件夹。不要选它的上一级（那一层还有 `service` 和 `mingpian-admin`），也不要只选里面的某个页面。
4. 左侧能看到 `pages`、`pages.json`、`manifest.json`、`common`、`my`。

## 第 3 步：在电脑浏览器里运行

1. 菜单选「运行」→「运行到浏览器」→「Chrome」。没有 Chrome 时选 Edge。
2. 第一次会下载编译器，底部控制台会出现「正在编译」。等到出现「编译成功」，浏览器会自己打开。
3. 地址以控制台里打印的为准。如果控制台里写的是别的端口，用控制台里的地址。
4. 打开后顶部标题是「名片分享」，底部应能看到 **首页、名片夹、企业、我的**。

HBuilderX 不要关。关掉后页面会打不开。

## 第 4 步：在微信小程序里运行（可选）

电脑浏览器已经能看，可以先不做这一步。

1. 安装并打开一次微信开发者工具，用微信扫码登录。
2. 在微信开发者工具里打开「设置」→「安全设置」，打开服务端口。
3. 回到 HBuilderX，菜单「工具」→「设置」→「运行配置」，把微信开发者工具的安装路径填上。
4. 菜单「运行」→「运行到小程序模拟器」→「微信开发者工具」。

`manifest.json` 里 `mp-weixin` → `appid` 可能已写过小程序号码。你不是该小程序的开发成员时，微信会提示 AppID 没有权限。自己练习时，把这个 `appid` 改成你自己的小程序 AppID，或继续只用浏览器运行。

微信开发者工具里如果提示域名不合法，本地调试可以勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。`127.0.0.1` 不是微信后台配置过的合法域名，不勾选这一项，模拟器里的接口会失败。

## 怎样算成功

首页能打开，底部四个按钮能点。按键盘 `F12`，点「网络」或 Network，再按一次浏览器的刷新。列表里的请求地址应是 `127.0.0.1:7777`。出现 `mpfx.xianmaxiong.com`，说明第 1 步没有保存，或改完后没有重新点「运行到浏览器」。

库里还没有名片时，首页可能提示去创建名片。这表示接口已经通了，只是还没有数据。用手机号注册需要短信。短信密钥没配时，验证码发不出去。密钥申请见 [用户端功能说明](用户端-功能说明.md) 末尾。

## 常见问题

**运行菜单是灰的，或提示没有浏览器**  
先安装 Chrome 或 Edge，再重启 HBuilderX。项目必须用「打开目录」打开 `uniapp`。

**一直停在「正在编译」，或浏览器是白屏**  
等控制台不再滚动。若出现红色报错，把第一行红色文字保留下来。常见原因是打开的文件夹不是 `uniapp`，或编译器还没下完。公司网络拦截下载时，换一个网络再运行一次。

**报错 `Failed to resolve import "dayjs/esm/index"`**  
`uni_modules` 里已有 uview-plus，缺的是项目根目录的 npm 依赖。在 `mingpian-uniapp` 执行 `npm install`，确认出现 `node_modules\dayjs` 后，再重新「运行到浏览器」。

**首页能开，但没有数据，登录失败**  
服务端没有启动，或 `common/config.js` 仍是原来的 `https://` 地址。先看服务端窗口是否还有「名片分享启动成功」，再改第 1 步，然后重新运行到浏览器。

**点上传后图片没保存**  
上传地址还指向原来的线上域名，或管理端「系统配置」里上传方式/对象存储没配好。先改第 1 步表格里的那几个文件，再在管理端确认是本地上传或已配好其中一家图床。

**微信开发者工具提示 AppID 无效或没有权限**  
换成你自己的小程序 AppID，或改用浏览器运行。
