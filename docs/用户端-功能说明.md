# 用户端功能说明

用户端是名片用户在手机或电脑网页里打开的那个应用。窗口标题是「名片分享」。底部一直有四个按钮：**首页、名片夹、企业、我的**。

下面按「打开后能点到什么」来写。每一处都说明：点进去做什么，以及会不会真的连到微信、支付宝、短信这些外面的服务。

## 这个端是给谁用的

- **名片用户**：创建与分享数字名片、管理人脉、加入企业、开通会员。
- **平台工作人员不使用这个应用。** 审核名片、看订单、改客服与密钥，在电脑上的管理端做。

## 首页

打开就是首页。

- **人脉搜索**：按条件找人脉 / 名片。
- **我的名片卡片**：展示当前名片的姓名、职位、公司、电话、地址等。没有名片时，会引导去创建。
- **编辑名片 / 更换样式 / 切换名片**：改内容、换模板样式、在多张名片之间切换。
- **分享名片**：生成分享图或拉起微信分享（小程序里走微信分享能力）。分享本身不经过支付宝。

首页名片数据来自数据库。库是空的，首页就是空引导态。这不是第三方人脉网站。

## 名片夹

底部「名片夹」用来管理收藏的名片和相关记录。

- 查看已收藏的名片。
- 与互换、最近查看等行为配套（具体入口以页面为准）。
- 互换次数等权益可能受会员配置限制。

## 企业

底部「企业」是企业主页相关能力。

- 企业名片展示与发布。
- 企业成员、申请加入、申请记录。
- 企业动态浏览与发布。
- 企业模板、名片码、名片数据统计等扩展页在分包 `my/Enterprise` 下。

企业入驻、审核状态由管理端处理。用户端提交后要等后台审核。

## 拍摄名片

「拍摄名片」页用于拍摄或识别纸质名片信息，再落到自己的数字名片流程。拍照权限由手机系统授予。识别结果是否调用外部 OCR，取决于后台是否配置了对应能力。

## 消息

「消息」或「消息中心」看平台通知与相关提醒。这是站内消息，不是手机短信。短信只用于登录验证码等场景。

## 登录、注册和找回密码

登录页有手机号相关的方式：

- **验证码登录或注册**：输入手机号，点获取验证码，再填收到的数字。验证码是服务端发出的短信，可走腾讯云、阿里云或短信宝，在管理端「系统配置」里切换。
- **密码登录**：手机号加密码。
- **忘记密码**：再验证一次手机号，然后设置新密码。
- **绑定手机号**：用微信等方式进来、还没有手机号时，要补绑手机号。

没配短信密钥，或短信签名没审核通过时，验证码发不出去，就无法用验证码注册。这时页面会停在发送失败，不是网络坏了。

## 我的

未登录时，头像旁边是「登录」。登录后显示昵称、职位、公司等信息。

头像下面常见数字：

- **最近访客**
- **最近查看**
- **最近邀请**
- **互换次数**

点数字进入对应列表。这是站内行为记录。

再下面是会员条。没开通时按钮写「立即开通」，已开通写「已开通」。点进去是「会员中心」，能看到管理端配置的价格和特权。付钱的规则见下面「付款」。

**其他服务**里常见：

- **AI 核查**：核查企业信息。依赖管理端配置的 AI 相关 Key，没配会失败。
- **邀请好友**：看邀请码和分享内容。对方用你的邀请注册后计入团队。
- **客服中心**：按系统配置里的客服类型走电话、企业微信或二维码。
- **团队分销**：推广身份开启时显示，看团队与收益。
- **意见反馈 / 帮助中心**：把问题发给平台，或看帮助文章。
- **设置中心**：协议、关于我们、改资料、注销。

设置里能打开的页面有：

- **隐私政策**
- **会员服务协议**
- **用户协议**
- **注销账号**

协议正文由后台维护。注销是提交注销申请，管理端「注销信息」里能看到，不是点一下账号立刻从数据库消失。

## 认证中心

「认证中心」上传身份或企业相关证明，提交后等管理端审核。审核中不能当成已经通过。认证照片要上传到服务器，按后台选定的本地或云存储保存。

## 钱包和订单

「我的钱包」可以看余额。相关页面还有：

- **钱包明细**
- **提现账号**
- **提现 / 提现记录**
- **充值**

提现是把申请交给平台审核。管理端在「财务中心」里处理。通过只表示平台同意，系统不会在这一步自动打进微信零钱或支付宝。

会员订单、待付款在会员开通流程里产生。付成功后以服务端收到支付通知为准。

## 名片榜单

「名片榜单」按人气等规则展示排名。数据来自自己的服务端，不是外部排行网站。

## 付款

开通会员或充值时，可选的付款方式取决于后台是否配齐：

- **余额**：扣「我的钱包」里的钱，不经过微信或支付宝。余额不够就不能选。
- **微信支付**：拉起微信支付。需要商户号、密钥，以及小程序或公众号的 AppId。
- **支付宝**：拉起支付宝。需要应用编号和密钥。

付成功后，微信或支付宝会通知服务端，订单才会变成已支付。付完钱立刻关页面、通知还没到时，订单可能要等一会儿才变。

这里没有银行卡快捷支付页面。

## 这个端真正会连到外面的服务

短信、微信、支付宝、图片存储、地图、企业微信客服、AI 核查的密钥填在管理端「系统配置」，由服务端去调用。只改用户端页面上的字，不会变成已经开通。

| 你在页面上做的事 | 要申请的服务 | 官网 | 填在哪里 | 没填密钥时 |
|---|---|---|---|---|
| 注册、登录、找回密码、改手机号 | 腾讯云 / 阿里云短信或短信宝 | https://cloud.tencent.com/product/sms 、 https://www.aliyun.com/product/sms 、 https://www.smsbao.com/ | 管理端「系统配置」 | 验证码发不出去 |
| 微信支付 | 微信支付商户平台 | https://pay.weixin.qq.com/ | 管理端「系统配置」 | 无法拉起微信支付 |
| 微信支付还要小程序或公众号 AppId | 微信公众平台 | https://mp.weixin.qq.com/ | 管理端「系统配置」 | 只有商户号时仍然付不了 |
| 支付宝付款 | 支付宝开放平台 | https://open.alipay.com/ | 管理端「系统配置」 | 无法拉起支付宝 |
| 头像、名片图、企业资质 | 本地上传，或阿里云 OSS / 七牛 / 腾讯云 COS | https://www.aliyun.com/product/oss 、 https://www.qiniu.com/ 、 https://cloud.tencent.com/product/cos | 管理端「系统配置」 | 上传失败，图片保存不住 |
| 地图选点 / 定位 | 腾讯地图或天地图 Key | https://lbs.qq.com/ 、 https://www.tianditu.gov.cn/ | 管理端「系统配置」 | 地图相关能力不可用 |
| 「客服中心」选了企业微信 | 企业微信客服 | https://work.weixin.qq.com/ | 管理端「系统配置」 | 小程序里打不开客服会话 |
| AI 核查企业 | 对应大模型 / API Key（如 qwen） | 以你选用的服务商为准 | 管理端「系统配置」 | 核查失败 |

短信三家只用开通其中一家。图片存储选本地或云上一家即可。

下面这些不用申请外面的 Key，服务端和数据库就绪就能用：

- 浏览、编辑已创建的名片（不含必须上传新图的步骤）。
- 名片夹收藏、访客与查看记录。
- 用钱包余额付款。余额不够时，微信和支付宝仍要上面的密钥。
- 复制客服微信号、查看后台配置的二维码图片。
- 提现只把账号和金额交给后台审核。
- 邀请关系、团队收益记账。

下面这些看起来像外面的服务，但当前不会真的连出去：

- 客服微信号和二维码：是展示和复制，不会自动加好友。
- 打电话：用的是手机自己的拨号，号码是后台填的客服电话。
- 邀请佣金：记在自己的数据库里，不是微信自动转账。

界面上的按钮、输入框、弹窗，用的是 uView Plus。它只负责长得像一个应用，不负责收款或发短信。
